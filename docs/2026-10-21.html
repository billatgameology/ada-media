Day 8 — the case of the phantom panels

2026-10-21

No session on October 20, so the log skips Day 7 — this is Day 8 by the calendar.

In code

Commits below are in project-ada-xr.

  • Idle media surface removed — the media state reported closed while a standalone media control stayed visible in XR. The idle surface is gone; the grid, titles and input targets now stay hidden until an explicit open/show/play request. Close, tracking/focus loss and finished exports can't reopen it.
  • Note deletion (in progress) — spatial notes had no delete control. Adding a delete action and a way to hide the note panel that's showing it.
  • No commit for October 21 — the panel fix shipped as a front-end-only deploy. As of this entry there is no matching commit in project-ada-xr, so the change isn't durable yet.

Why / what I learned

  • Panels that appear without being asked are worse than missing features — they make the space feel haunted. "Only when requested" is the rule for every surface.
  • Small fixes still count as days: the goal is that every session leaves the room a little more predictable.
  • A front-end deploy is not a checkpoint. If the change isn't committed, the next session can't review it, diff it, or roll it back.
