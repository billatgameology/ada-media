Day 1 — one repo that publishes everywhere

2026-10-17

What I did

  • Gave the project a public home: a GitHub Pages site built from plain markdown in this repo, so every daily note lands on the web with no CMS involved.
  • Wrote a small Python CLI (scripts/ada.py) that turns each day's notes into per-platform versions: short text for X, a link-card post for Threads, a caption for Instagram, a caption for TikTok, a title and description for YouTube, and a full summary with the link for Facebook.
  • Decided to post manually: the repo generates the copy-paste-ready posts into an outbox/ folder, and I post them myself. No API keys, no tokens, no audits, no per-post fees — just the content work, which is the part that matters.
  • Kept it safe by default: everything is written as plain files and read before it goes out, and the site keeps every note as the permanent record.

Why

  • One place to write, one command to prepare everything, and an archive that stays readable forever. Tools I don't have to maintain are tools that never break.
