Day 1 — one repo that publishes everywhere

2026-10-17

What I did

  • Gave the project a public home: a GitHub Pages site built from plain markdown in this repo, so every daily note lands on the web with no CMS involved.
  • Wrote a small Python CLI (scripts/ada.py) that turns each day's notes into per-platform posts: short link-free text for X, text with a link card for Threads, captions for Instagram, descriptions for YouTube and TikTok, and a full summary for Facebook.
  • Wired the pipeline to the platform APIs with a dry-run preview, so nothing gets posted by accident: publish shows exactly what would go out, publish --live sends it.

Why

  • One place to write, one command to publish, one archive that stays readable forever. No dashboards to log into and no subscriptions — for a project this size, that's the whole point.

Next

  • Connect the accounts (Threads and YouTube first — they're free and painless), then take day 2 live.
