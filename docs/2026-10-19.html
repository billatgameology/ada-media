Why / what I learned

  • The assistant stops being a chat window when it can operate the same tools I use. Chrome on the Mac is the first demo: point at the work, talk about it, let Ada do the typing.
  • The YC form is a good forcing function. A real task with real stakes exposes everything the demo hides — notes that don't render, replies that don't arrive, cubes that won't close.
  • "Every item should be relocatable by just a voice command" is now a product rule, not a one-off request. The mirrored screen can't do it yet, and that's an implementation gap worth naming.
    Evidence: com.oculus.browser-20261019-063325-0.mp4 @ 3:49–4:17.
  • Watching Ada work in Chrome while I sat in the headset was the first time the assistant felt like it was inside my actual software instead of a demo panel beside it.
