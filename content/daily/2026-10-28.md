## In the headset

- **The chart appears** — the first sample request is rejected with a stale-state error, so Ada stops instead of replaying it. A second request creates “Sample: weekly visitors,” a bar chart with an exact-values table. Selecting a bar highlights the matching row. Hide and Close both make the exhibit disappear, which is the next control bug.
  *Evidence: `com.oculus.vrshell-20261028-160105-0.mp4` @ 2:00–8:00.*
- **The overlap test** — ordinary speech reaches Ada while she is speaking; the microphone and the reply no longer block each other. “Stop speaking” still goes into the conversation queue, so it does not cut audio immediately. Bill rejects voice and noise as the trigger and asks for a deliberate open palm: stop only while Ada is speaking, keep the work and microphone running.
  *Evidence: `com.oculus.browser-20261028-111238-0.mp4` @ 0:00–8:30.*
- **The memory request** — after the chart test, Bill asks for panels to remember where they are placed and for a billboarding control on every panel, next to Close. The live Save request returns NO_ACTIVE_SCENE; no target snapshot, pose, write or ACK is obtained. The current positions stay untouched and the request becomes the next extension.
  *Evidence: `com.oculus.browser-20261028-144913-0.mp4` @ 7:00–9:16; `com.oculus.vrshell-20261028-160105-0.mp4` @ 4:41–9:31.*
- **What already passes** — Combine with Previous works again in this trial, the floating notification bubble is gone, and palm-stop audio works after the wrist angle is relaxed. The saved room anchor and room grid are still missing on the morning load.
  *Evidence: `com.oculus.vrshell-20261028-080144-0.mp4` @ 0:00–6:00; `com.oculus.browser-20261028-144913-0.mp4` @ 9:16–9:46.*

## Why / what I learned

- A chart is not a web page floating in space. It needs stable data, exact rows, a readable table and a selection that means the same thing in every view.
- Full-duplex voice is the right default: I should be able to interrupt with a new thought without stopping the work already in flight. The stop gesture should be deliberate, not incidental noise.
- “Remember this” is a different promise from “put it here.” The Save failed honestly, and that is better than a partial layout that looks saved.
