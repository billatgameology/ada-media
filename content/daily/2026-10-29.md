## In code

- **The save repair** — the native IWSDK float32 tracking boundary was falsely invalidating Save; only the existing owned anchor sampler now normalizes its rotation. The release passes 3,052 cases with 0 failures, 83 focused checks and 10 real-IWSDK browser checks, served as `app-B6krKhpi.js`. Physical save and restore remain unverified.
  *Evidence: `cf664ea`; `project_ada_xr/docs/current-test-fixes-2026-10-29.md`.*
- **Combine evidence pages instead of vanishing** — an oversized request-experience reply that was truncated from 93,882 to 64,000 characters now returns an explicit incomplete manifest. Sections can be read in 4,096-character chunks with exact bytes and SHA-256, then reconstructed unchanged. This fixes a demonstrated read-consumption defect, not every intermittent Combine cause.
  *Evidence: `cf664ea`; `project_ada_xr/docs/retest-repairs-2026-10-29.md`.*
- **Billboarding becomes one control** — native UIKit rendering, a 16×5 cm labeled control, top-right menu integration and hover-only reveal. The release records 447 header, 145 actual-quad/depth, 45 native input/persistence and 56 screenshot/library-photo adjacency checks.
  *Evidence: `cf664ea`; `project_ada_xr/docs/current-test-fixes-2026-10-29.md`.*
- **The publication** — 94 task paths in `cf664ea`, closing the October 29 repair batch and preserving the pre-feature checkpoint. No owner reload, scene write or automatic retry was performed as part of the publication.
  *Evidence: `cf664ea`; `project_ada_xr/docs/handoffs/2026-10-29-pre-feature-checkpoint.md`.*

## Why / what I learned

- A room that looks aligned can still fail to save. The difference between “the outlines match” and “the coordinates are admissible” is where the whole promise lives.
- The smallest numeric error can invalidate the largest workflow. A 4.2e-8 rotation change is invisible in the headset and fatal to the save.
- It is better to show the failed Save than to write a partial layout. The next run can trust the readback because the last one did not lie.
