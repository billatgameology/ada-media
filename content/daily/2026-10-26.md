## In code

- **Retained grounding is a route, not a bypass** — a current, ready, exact-revision note-content intention can use its verified original event. Full accepted input and the exact closed action must still match; expired, foreign, ambiguous or unverified context refuses. The legacy selected-or-named guard stays for everything else.
  *Evidence: `abae2f1`; `project_ada_xr/docs/core-continuation-repair-2026-10-26.md`.*
- **Composition is declared before effects** — one accepted request can carry a bounded sequence of ordinary note operations, but model Preview, Accept/Cancel and Save remain separate decisions. A confirmed prefix stays inspectable when a successor is rejected, and uncertain work is never replayed against a replacement.
  *Evidence: `abae2f1`; `project_ada_xr/docs/operation-lifecycle-foundation-2026-10-26.md`.*
- **Collections are paged, not capped** — shared byte-bounded readers replace the old eight-model coupling. Forty-two small models stay addressable across pages, a 320-photo fixture scans past 2,200 candidates, and resident pressure returns an exact prefix instead of silently evicting work.
  *Evidence: `abae2f1`; `project_ada_xr/docs/shared-collections-foundation-2026-10-26.md`.*
- **The release** — `assets/app-CtF0Ce8S.js`, matched frontend/backend, 2,631 cases with 2,624 passing, 0 failures and 7 optional skips. No owner reload or physical acceptance was claimed.
  *Evidence: `7268166`; `project_ada_xr/docs/core-continuation-repair-2026-10-26.md`.*

## Why / what I learned

- A collaborator needs the thread of the task, not the last thing selected. Selection is a pointer; the intention is the memory.
- “One request, several steps” only works if each step has its own authority and receipt. The sequence is not a transaction, and it should not pretend to be one.
- The same pattern keeps showing up: exact identity, current evidence, a bounded action, a truthful outcome. That is becoming the shape of the whole system.
